핵심 기능

기능문제고친 방법결과
실시간 배틀런같은 티어 러너와 1:1로 달리며, 거리 차이를 트랙 위 아바타로 보여 줍니다.직접 테스트했을 때 상대 아바타가 트랙 가운데에서 갑자기 나타나고, 움직임도 끊겼습니다.상대 위치 쪽 트랙 가장자리에서 등장하게 하고, 출발 전 아바타를 미리 합성하도록 6회 수정했습니다.에뮬레이터 녹화로 상대 아바타가 등장하는 위치와 움직임을 확인했습니다.
크루런크루원들이 함께 출발해 달리는 기능입니다.직접 써 보니 크루런을 만들어도 크루원이 바로 알 수 없었고, 대기실과 결과도 바로 갱신되지 않았습니다.실시간 신호로 갱신하고 연결이 끊기면 3초마다 다시 조회하게 했습니다. 전원 준비 시 자동 출발도 제안해 넣었습니다.크루런의 전체 흐름을 자동 시험(e2e)으로 확인했습니다.
셀카 아바타셀카로 만든 얼굴에 러닝량에 따라 그을림이 생기는 기능입니다.셀카 얼굴은 한 장짜리 그림이라 색을 씌우면 피부뿐 아니라 머리카락과 눈까지 어두워졌습니다.얼굴을 피부, 눈, 헤어 층으로 나누고, 피부 층에만 몸과 같은 색 보정을 적용하자고 제안했습니다.러닝량 0, 50, 100에서 피부 픽셀만 어두워지는지 자동 시험으로 확인하고, 프로필과 랭킹에도 같은 규칙을 적용했습니다.

담당 역할

AI 활용
AI 작업 규칙과 세션 메모리를 만들고, 보안 리뷰와 작업별 모델 선택을 개발 절차에 넣었습니다.
운영
Pod 자동 확장(HPA)과 동시 중단 한도(PDB)로 무중단 배포를 했고, Jenkins에서 테스트(pytest), 이미지 취약점 검사(Trivy), 이미지 빌드(Kaniko)를 거치게 했습니다. staging에는 Spot VM과 예약 실행(CronJob)을 적용했습니다. GCP 결제 기록으로 보면 클러스터 전체 하루 비용이 약 17,500원(적용 전날)에서 약 12,000원(적용 뒤 9일 평균)으로 약 31% 줄었습니다.

사용 기술

일정이 빠듯한 점을 고려해 SSAFY에서 배운 기술과 미리 공부해 둔 기술 중에서 골랐습니다.

Django 5.2, DRF
2명이 현물·선물 거래와 자동매매까지 만들어야 해서, 이미 배운 Django로 개발 속도를 확보했습니다.
PostgreSQL
주문이 체결될 때 잔고가 어긋나면 안 되어, 트랜잭션 정합성을 보장하는 PostgreSQL을 골랐습니다.
Django Channels, Redis
Django를 그대로 쓰면서 코인별 채팅과 실시간 시세를 WebSocket으로 보내려고 골랐습니다. Redis로 여러 워커가 같은 메시지를 받게 했습니다.
Celery, Celery Beat
캔들 동기화와 자동매매 평가를 주기적으로 실행했습니다.
pandas-ta
차트, 자동매매, 백테스트에서 같은 지표 계산을 쓰도록 했습니다.
GKE
부하에 따라 Pod를 늘리고(HPA) 무중단 배포를 하려고 골랐습니다.
Jenkins
테스트, 이미지 취약점 검사, 이미지 빌드를 클러스터 안에서 한 파이프라인으로 실행하려고 골랐습니다.

핵심 기능

기능문제고친 방법결과
실시간 차트Upbit 시세로 캔들 차트와 보조지표를 그리는 기능입니다.진행 중인 봉을 처음 받은 값 그대로 저장해, 60분봉 200개 중 100개가 Upbit와 달랐습니다.같은 시각의 봉을 갱신하고 잘못 저장된 행을 복구했습니다. 전략은 봉이 마감된 뒤 평가하도록 바꿨습니다.캔들 누락 탐지와 정기 감시를 추가해 데이터가 다시 어긋나면 알 수 있게 했습니다.
자동매매와 캔들 동기화Celery로 캔들을 모으고 전략을 주기적으로 평가하는 기능입니다.운영 중 260개 마켓을 매분 조회하다 초당 약 8회 호출 한도에 걸려, 작업이 분당 5개씩 쌓이고 캔들 누락 위험이 생겼습니다.차트를 보거나 전략이 켜진 마켓만 동기화했습니다. 락으로 겹친 작업을 건너뛰고 실패한 마켓만 다시 시도하게 했습니다.새로 추가한 시험 5종을 포함해 467개 이상의 시험을 통과했습니다.
실시간 채팅거래 화면에서 사용자끼리 실시간으로 대화하는 기능입니다.한글 한 글자 입력 후 Enter를 누르면 같은 메시지가 최대 5번 전송됐고, 호출 제한에 걸려 다음 메시지가 사라졌습니다.한글 조합 중에는 전송하지 않고, 200ms 안에 같은 내용을 다시 보내지 않도록 바꿨습니다.한글 입력 후 Enter를 눌러도 메시지가 한 번만 전송됩니다.
